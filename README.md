# Notes Manager (Python Mini-Project)

A command line notes manager built with Python using **Functions** and **File Handling**.
Notes are saved in a text file (`notes.txt`) so they are still there when you reopen the program.

## Features:
- Add a new note (with automatic date and time)
- View all notes in a table
- Search notes by keyword
- Edit an existing note
- Delete a note
- Clear all notes (with confirmation)
- Input validation: empty input, invalid numbers, out of range choices, duplicate notes and wrong yes/no answers are all handled

## Requirements:
- Python 3.6 or later
- No external libraries needed

## How to Run:
1. Download or copy `notes_manager.py` into a folder.
2. Open a terminal (or Command Prompt) in that folder.
3. Run the program:
4. Choose an option from the menu by typing a number (1-7) and pressing Enter.

`notes.txt` is created automatically in the same folder when you add your first note.

## Menu Options:
| Option | Action |
|--------|--------|
| 1 | Add a new note |
| 2 | View all notes |
| 3 | Search notes |
| 4 | Edit a note |
| 5 | Delete a note |
| 6 | Clear all notes |
| 7 | Exit |

## Concepts Used:
- Functions
- File handling (read and write)
- Input validation
- Error handling with `try/except`
